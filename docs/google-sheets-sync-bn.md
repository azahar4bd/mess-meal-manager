# গুগল শিট সিঙ্ক সেটআপ গাইড (বাংলা)

**যার জন্য:** Mess Meal Manager — অফিস `Gobra01` (কোড `GOBRA0101`)
**সময় লাগবে:** প্রায় ১০ মিনিট · **খরচ:** নেই (সাধারণ Google অ্যাকাউন্টেই চলে)

> **নীতিগত কথা (spec §65):** অ্যাপের আসল ডেটাবেস **PostgreSQL**। গুগল শিট শুধু একটি
> **রিপোর্টিং কপি** — দেখা, প্রিন্ট, শেয়ার করার সুবিধার্থে। তাই সিঙ্ক কোনো কারণে ব্যর্থ হলেও
> অ্যাপের কোনো ডেটা হারাবে না বা বন্ধ হবে না; শুধু শিটটা হালনাগাদ হবে না।

## ২ মিনিটে সারসংক্ষেপ

1. একটা খালি Google Sheet খুলুন → নাম দিন `Mess Meal Manager - Gobra01`
2. **Extensions → Apps Script** → সব কোড মুছে `google-apps-script/Code.gs`-এর পুরো কোড পেস্ট করে সেভ
3. **Deploy → New deployment → Web app** → Execute as: **Me**, Access: **Anyone** → URL কপি (`/exec` দিয়ে শেষ)
4. অ্যাপে লগইন → **☁ গুগল শিট** ট্যাব → "সিংক সেটিংস" কার্ডে URL দুটো বসান → **💾 সেটিংস সংরক্ষণ**
5. **🔌 Connection Test (ping)** → "✓ সংযোগ সফল" দেখলে → **☁ Full Sheet Sync**

## ধাপ ১ — গুগল শিট তৈরি

1. https://sheets.google.com খুলুন → **+ Blank** (খালি স্প্রেডশিট)।
2. উপরে বাঁ দিকে নাম লিখুন: `Mess Meal Manager - Gobra01`
   (অ্যাপের ফর্মেও এই নেমিং-ই পরামর্শ দেওয়া আছে: *Naming: Mess Meal Manager - &lt;Office Name&gt;*)
3. ব্রাউজারের অ্যাড্রেসবার থেকে শিটের লিংকটা কপি করে রাখুন — দেখতে এমন:
   `https://docs.google.com/spreadsheets/d/1AbC…xyz/edit`
4. শিটে আলাদা করে কোনো ট্যাব/ঘর লিখতে হবে **না** — সিঙ্কের সময় স্ক্রিপ্ট নিজেই সব ট্যাব বানিয়ে নেবে।

## ধাপ ২ — Apps Script কোড বসানো

1. শিটের ভেতরে মেনু থেকে: **Extensions (এক্সটেনশন) → Apps Script**
2. এডিটরে যে ডিফল্ট কোড (`function myFunction() {}`) আছে, **পুরোটা মুছে ফেলুন**।
3. এই প্রজেক্টের ফাইল **`google-apps-script/Code.gs`** (৫৯০ লাইন) খুলে **সবটুকু কপি** করে এডিটরে পেস্ট করুন।
4. **Ctrl + S** চাপুন (বা ডিস্ক আইকন)। প্রজেক্টের নাম দিন: `Gobra01 Sync`
5. কোডে হাত দেওয়ার দরকার নেই — কনফিগ ব্লকটা এমন:

```js
var CONFIG = {
  SPREADSHEET_ID: '',      // খালি রাখুন → যে শিটে স্ক্রিপ্টটি আছে সেটাই ব্যবহার হবে
  API_TOKEN: '',           // ঐচ্ছিক নিরাপত্তা টোকেন (নিচের "টোকেন" অংশ দেখুন)
  FREEZE_HEADER: true,     // হেডার সারি ফ্রিজ করা থাকবে
  WRITE_SYNC_LOG: true,    // "99_সিংক_লগ" ট্যাবে প্রতিটি সিঙ্কের রেকর্ড
  MAX_ROWS: 60000,         // এক রিকোয়েস্টে সর্বোচ্চ কত সারি (নিরাপত্তা সীমা)
};
```

## ধাপ ৩ — (ঐচ্ছিক) নিরাপত্তা টোকেন

ডিফল্ট অবস্থায় `API_TOKEN` খালি, অর্থাৎ যার কাছে `/exec` URL আছে সে-ই স্ক্রিপ্ট কল করতে পারবে।
URL-টা অনুমান করা প্রায় অসম্ভব (লম্বা এলোমেলো আইডি), তাই **খালি রাখলেও চলবে**।

আরও নিরাপত্তা চাইলে:

1. `Code.gs`-এ বসান: `API_TOKEN: 'আপনার-গোপন-শব্দ',` → সেভ → **নতুন করে ডিপ্লয়** (ধাপ ৪)।
2. অ্যাপে URL দেওয়ার সময় টোকেনটা **URL-এর সাথেই** যোগ করুন, কারণ অ্যাপ আলাদা করে টোকেন পাঠায় না:

```
https://script.google.com/macros/s/AKfycb…/exec?token=আপনার-গোপন-শব্দ
```

অ্যাপ তখন নিজে থেকেই `&action=ping` যোগ করবে — অর্থাৎ `?token=…` দিলেই কাজ করবে।
টোকেন মিল না হলে স্ক্রিপ্ট `403` ফেরত দেবে।

## ধাপ ৪ — Web App হিসেবে ডিপ্লয়

1. Apps Script এডিটরের উপরে ডান দিকে: **Deploy → New deployment**
2. বাঁ দিকের গিয়ার আইকনে ক্লিক করে টাইপ বাছুন: **Web app**
3. এই দুটো সেটিংস **অবশ্যই** মিলিয়ে নিন:

| সেটিংস | কী দেবেন | কেন |
|---|---|---|
| **Execute as** | **Me** (আপনার Google অ্যাকাউন্ট) | স্ক্রিপ্টের শিটে লেখার অনুমতি আপনার কাছে |
| **Who has access** | **Anyone** | অ্যাপের সার্ভার (Vercel) থেকে কল করা হয় — আপনার Google লগইন সেখানে নেই |

4. **Deploy** → Google-এর অনুমতি চাইলে: *Review permissions* → আপনার অ্যাকাউন্ট → **Advanced** →
   *Go to Gobra01 Sync (unsafe)* → **Allow**
   ("unsafe" লেখাটা আসে কারণ স্ক্রিপ্টটি আপনার নিজের তৈরি, Google যাচাই করা নয় — এটা স্বাভাবিক)
5. ডিপ্লয়মেন্ট সফল হলে **Web app URL** কপি করুন। দেখতে এমন:
   `https://script.google.com/macros/s/AKfycbx…xyz/exec`

> ⚠ **`/exec` দিয়ে শেষ হতে হবে** — `/dev` দিয়ে শেষ URL কাজ করবে না (ওটা শুধু এডিটরের টেস্ট URL)।
> ⚠ পরে `Code.gs`-এ কিছু বদলালে **Deploy → Manage deployments → ✎ (Edit) → Version: New version → Deploy**
> করতে হবে, না হলে পুরনো কোডই চলতে থাকবে।

## ধাপ ৫ — অ্যাপে URL বসানো

**সহজ পথ (ম্যানেজার বা অ্যাডমিন লগইন দিয়ে):**

1. https://messmealmanager.vercel.app → লগইন (`01994259616` — Sakib, অথবা অ্যাডমিন)
2. সাইডবার/ট্যাববার থেকে **☁ গুগল শিট** ট্যাবে যান
3. **"সিংক সেটিংস / Sync Settings"** কার্ডে:
   - **Google Apps Script Web App URL (/exec)** → ধাপ ৪-এর URL পেস্ট করুন
   - **Google Sheet URL (এই অফিসের স্প্রেডশিট)** → ধাপ ১-এর শিট লিংক পেস্ট করুন
4. **💾 সেটিংস সংরক্ষণ** চাপুন
5. **🔌 Connection Test (ping)** চাপুন → সবুজ বাক্সে **"✓ সংযোগ সফল"**, সাথে Spreadsheet-এর নাম,
   আইডি ও ট্যাব তালিকা দেখাবে
6. এবার **☁ Full Sheet Sync** চাপুন → কয়েক সেকেন্ডে শিটে সব ট্যাব ভরাট হয়ে যাবে

**বিকল্প পথ (অ্যাডমিন প্যানেল থেকে):** অ্যাডমিন লগইন → **অ্যাডমিন** → **অফিস** ট্যাব →
`Gobra01`-এর পাশে সম্পাদনা → *Google Sheet URL* ও *Apps Script URL* ঘরে বসিয়ে **Save**।
(প্রতিটি অফিসের জন্য আলাদা শিট ও আলাদা স্ক্রিপ্ট URL — এক অফিসের শিটে আরেক অফিসের ডেটা যায় না।)

**অটো সিঙ্ক:** একই ট্যাবে **Auto Sync** বক্সে টিক দিলে *প্রতিটি সেভের পর* শিট নিজে থেকে হালনাগাদ হবে।
না চালাতে চাইলে খালি রাখুন — তখন শুধু **Full Sheet Sync** চাপলেই সিঙ্ক হবে।

## ধাপ ৬ — শিটে যা তৈরি হবে

সিঙ্কের পর শিটে এই ৯টি ট্যাব দেখতে পাবেন (নাম ও কলাম অ্যাপের `sheet-structure` অনুযায়ী নির্দিষ্ট):

| ট্যাব | কী থাকে | কলাম |
|---|---|---|
| `00_অফিস_ইনফো` | অফিসের পরিচয় ও মাসের তথ্য | Key, Value |
| `01_সদস্য_তালিকা` | সদস্য রোস্টার | MemberID, Name, Role, Phone, IsActive, OfficeID, MonthID |
| `02_দৈনিক_মিল_খাতা` | দিন-ভিত্তিক মিল | MonthID, Year, Month, Day, Date, MemberID, MemberName, Meals |
| `03_বাজার_খরচ` | বাজারের এন্ট্রি | EntryID, MonthID, Date, Day, MemberID, BuyerName, Category, Items, Amount, Note |
| `04_জমা_ও_তহবিল` | জমা, চাঁদা, স্থায়ী তহবিল | EntryID, MonthID, Date, Day, MemberID, MemberName, Amount, Note, Type |
| `05_অন্যান্য_আয়` | অন্যান্য আয় | EntryID, MonthID, Date, Day, Title, Amount, Note |
| `06_হিসাব_সামারি` | মাসের সামারি | MonthID, MonthName, TotalMembers, TotalMeals, **MealRate**, TotalBazar, OtherIncome, NetMealCost, PermanentFund, SharedExtra, LastBalance, SyncedAt |
| `07_দেনা_পাওনা` | সদস্যভিত্তিক হিসাব | MonthID, MemberID, Name, Role, TotalMeals, MealRate, MealCost, IndividualExtra, SharedExtra, TotalMealCost, PermanentFund, **DenaPoana**, Status |
| `99_সিংক_লগ` | প্রতিটি সিঙ্কের রেকর্ড | সময়, সফল/ব্যর্থ, সারি সংখ্যা, কত সময় লেগেছে |

> হিসাবের নিয়ম অপরিবর্তিত: **MealRate = (মোট বাজার − অন্যান্য আয়) ÷ মোট মিল**, স্থায়ী তহবিল আলাদা,
> শেয়ার্ড এক্সট্রা সবার মধ্যে সমান ভাগ — শিটেও সেই সংখ্যাই বসে।

| কোড বদলানোর পরেও পুরনো আচরণ | নতুন ভার্শন ডিপ্লয় হয়নি | Manage deployments → ✎ → Version: **New version** → Deploy |

## নিরাপত্তা

- Apps Script-এর Access "Anyone" মানে *স্ক্রিপ্টের URL জানা যেকোনো ব্যক্তি কল করতে পারে* — এটা শিটের
  শেয়ারিং সেটিং নয়। শিটের শেয়ারিং আলাদাভাবে নিয়ন্ত্রণ করুন (যেমন "Only people I share with")।
- বেশি নিরাপত্তা চাইলে ধাপ ৩-এর টোকেন ব্যবহার করুন।
- অ্যাপের আসল ডেটা PostgreSQL-এ; শিটে শুধু কপি যায়। পাসওয়ার্ড বা সেশন কখনো শিটে লেখা হয় না।
